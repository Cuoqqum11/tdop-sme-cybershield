# Simulation Environment

This folder contains scripts and scenarios for simulating benign behavior and attack behavior in an isolated lab environment.

Important:

> All attack simulations must only be run inside an isolated lab environment.

Planned benign scenarios:

- normal login activity,
- normal web traffic,
- normal file access,
- office-hour activity.

Planned attack scenarios:

- brute force login,
- suspicious off-hours login,
- web exploit attempt,
- suspicious PowerShell execution,
- mass file access,
- ransomware-like file behavior.
