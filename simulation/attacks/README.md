# Attack Simulation

This folder will contain scripts that simulate attacks in a controlled lab environment.

Examples:

- brute force SSH login,
- suspicious off-hours login,
- web SQL injection attempt,
- web XSS attempt,
- suspicious PowerShell execution,
- mass file access,
- ransomware-like file activity.

Important:

> Only run these scripts inside an isolated lab. Never run them against production systems or networks without authorization.
