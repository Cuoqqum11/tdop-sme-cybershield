# Competition Alignment: RND to Startup

## Competition Track Strategy

The project should aim for the **Project Track** if a working prototype can be demonstrated.

If the prototype is not ready, the project may still enter the **Idea Track**, but the stronger path is Project Track because the research already has implementation potential.

## Project Track Requirements

The Project Track expects:

- clear development progress,
- a prototype, MVP, or experimental result,
- evidence of implementation,
- feasibility of commercialization.

SME CyberShield satisfies this by providing:

- a working backend,
- Wazuh integration,
- anomaly detection pipeline,
- dashboard prototype,
- simulated attack evaluation,
- SME-focused product definition.

## Judging Criteria Alignment

### 1. Problem and Market Need — 20%

Project response:

Vietnamese SMEs face increasing cyber threats but lack budget, staff, and expertise.

Evidence:

- Viettel 2024 cybersecurity report,
- SME cybersecurity literature,
- “3U” problem: Unaware, Unfunded, Uneducated.

### 2. Innovation / R&D — 25%

Project response:

The innovation is not the Isolation Forest algorithm alone.

The innovation is combining:

- Wazuh open-source XDR,
- lightweight anomaly detection,
- incident correlation,
- explainable risk scoring,
- response recommendations,
- local-first deployment,
- SME-oriented design.

### 3. Implementation Capability — 20%

Project response:

The team will demonstrate:

- working API,
- Wazuh alert ingestion,
- anomaly scoring,
- incident creation,
- dashboard,
- simulated attack demo.

### 4. Business Model and Impact — 15%

Project response:

The product can generate revenue through:

- subscription,
- deployment service,
- managed monitoring,
- compliance-oriented reporting.

Social impact:

- improves SME cybersecurity readiness,
- reduces cost of protection,
- supports local data control.

### 5. Team Capability — 10%

Project response:

Team roles:

- backend and ML development,
- documentation and business model,
- security testing and evaluation,
- frontend/demo preparation.

### 6. Presentation and Defense — 10%

Project response:

Prepare:

- 5-minute demo,
- clear problem statement,
- working dashboard,
- evaluation results,
- concise pitch deck.

## Key Message for Judges

> We are not only proposing research. We are building a working lightweight XDR prototype that transforms open-source cybersecurity tools into a practical product for Vietnamese SMEs.
